# Borradores de contenido (`/content`)

Aquí van los `.md` que redactes para las secciones que aún dependen de tu contenido real. Cuando estén listos, avísame y los transcribo a `/data/*.json` (ver `data/README.md` para el esquema).

- `promociones.md` → promoción(es) del mes vigente
- `catalogo.md` → equipos y accesorios (puede ser la salida directa de `/ficha-tecnica`)
- `faq.md` → preguntas frecuentes reales del negocio

No hace falta seguir un formato estricto: puedes pegar el texto tal cual lo tengas (desordenado está bien), yo lo normalizo al pasarlo al JSON. Si prefieres, también puedes simplemente pegarme el contenido directo en el chat en vez de guardarlo aquí — lo que te resulte más cómodo.
